# Blockierender Fehler (Monkeytype-Stil)

Falsche Taste: Der Cursor springt NICHT vor; die Stelle wird rot markiert; der Spieler muss
die korrekte Taste drücken, um weiterzukommen. Jeder Fehldruck zählt als Fehler in der
Tasten-Genauigkeit.

**Considered Options**: Nicht-blockierend (weiter tippen, Fehler nur zählen). Abgelehnt:
schwächeres Lernsignal – der Spieler muss aktiv korrigieren, was das korrekte Tippen
erzwingt und zum Lernziel passt.

**Consequences**: Spieler, die viele Fehler machen, kommen langsamer voran (doppelte
Bestrafung: Genauigkeit + Tempo). Das ist gewollt – Technik schlägt rohes Tempo.
